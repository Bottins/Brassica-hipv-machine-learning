# Volatile-mediated responses in *Brassica rapa*

This repository contains the data and Python code used to analyse volatile-mediated responses in receiver plants. The experiment compared *Brassica rapa* plants exposed to constitutive volatile organic compounds (VOCs) or herbivore-induced plant volatiles (HIPVs), with or without a subsequent challenge by *Athalia rosae* larvae.

The analysis combines gas-exchange and chlorophyll-fluorescence measurements, GC-MS VOC profiles and consumed leaf area. A Gradient Boosting classifier is evaluated by stratified five-fold cross-validation for two tasks:

1. classification of all four experimental treatments;
2. comparison of herbivore-challenged receivers previously exposed to constitutive VOCs or HIPVs.

## Repository structure

```text
.
|-- data/
|   |-- raw/                         Original measurement workbooks
|   `-- processed/                   Dataset used in the analysis
|-- src/
|   |-- prepare_data.py              Cleans sample identifiers and merges the raw data
|   `-- run_analysis.py              Runs the models and generates figures and tables
|-- results/
|   |-- figures/                     Generated article figures
|   `-- tables/                      Generated model summaries and predictions
|-- .gitignore
|-- README.md
`-- requirements.txt
```

The files in `results/` are generated by the analysis and are therefore not tracked by default.

## Data

The `data/raw` directory contains the original tables supplied for analysis:

- `gas_exchange_fluorescence.xlsx`: 120 samples and 20 physiological variables;
- `voc_gcms.xlsx`: 132 GC-MS records and 20 VOC variables;
- `leaf_area_damage.xlsx`: measurements of consumed leaf area.

The analysis-ready file, `data/processed/receiver_plant_dataset.xlsx`, contains 120 matched samples and 41 numeric variables. It is included so that the statistical analysis can be run directly. It can also be regenerated from the raw workbooks with `prepare_data.py`.

Treatment codes are defined as follows:

| Code | Volatile exposure | Subsequent herbivory | Manuscript label |
|---|---|---:|---|
| `h0h0` | Constitutive VOCs | No | rC |
| `h0h1` | Constitutive VOCs | Yes | rC + herbivore |
| `h1h0` | HIPVs | No | rHIPV |
| `h1h1` | HIPVs | Yes | rHIPV + herbivore |

Further information on variables and data preparation is provided in [`data/README.md`](data/README.md).

## Installation

Python 3.10 or later is recommended. From the repository root, create a virtual environment and install the dependencies:

```bash
python -m venv .venv
```

On Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

On macOS or Linux:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Reproducing the analysis

The processed dataset is already included. To run the complete analysis:

```bash
python src/run_analysis.py
```

This command regenerates the cross-validated model results, feature-set ablation, SHAP ranking, PCA visualisations and all article figures. Outputs are written to `results/figures` and `results/tables`.

To rebuild the processed dataset first:

```bash
python src/prepare_data.py
python src/run_analysis.py
```

All paths are resolved relative to the repository, so the commands can be run from any working directory. Randomised analyses use a fixed seed (`42`).

## Robustness-focused analysis

The revised manuscript analysis can be reproduced with:

```bash
python src/run_analysis_v2.py
```

This version adds 30 repetitions of stratified five-fold cross-validation,
30 permuted-label null datasets, leave-one-experimental-run-out validation,
repeated feature-set ablation and out-of-fold SHAP values. Outputs are written
to `results_v2/figures` and `results_v2/tables`.

## Main outputs

The analysis writes the following tables:

- `model_performance_summary.csv`: overall cross-validated scores;
- `cross_validation_folds.csv`: accuracy and F1 score for each fold;
- `focused_cross_validated_predictions.csv`: out-of-fold predictions for the binary comparison;
- `feature_set_ablation.csv`: performance obtained from each measurement domain;
- `shap_feature_importance.csv`: global SHAP ranking;
- `focused_feature_ranking.csv`: SHAP and Gradient Boosting importance in one table.
